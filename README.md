# Task Manager

Task Manager is an Android application designed to help users efficiently organize, track, and manage their daily tasks.

## 🚀 Features

- **Task Management**: Create, view, and organize your tasks.
- **User-Friendly Interface**: Intuitive design for seamless task tracking.
- **Android Native**: Built using modern Android development practices.

## 🛠️ Technology Stack

- **Language**: [Kotlin](https://kotlinlang.org/)
- **Build System**: Gradle
- **IDE**: Android Studio

## 📦 Getting Started

### Prerequisites
- Android Studio (Latest stable version recommended)
- Java Development Kit (JDK) 17+
- An Android Emulator or physical device

### Installation & Build

1. Clone the repository or download the source code.
2. Open the project folder in **Android Studio**.
3. Allow Gradle to sync the dependencies.
4. Run the app on an Android Emulator or physical device by clicking the **Run** button (▶) in Android Studio.
